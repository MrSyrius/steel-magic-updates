# Steel & Magic — grafiki kart

Katalog docelowy: `web/game/cards/grafiki/thumb/` i `web/game/cards/grafiki/portrait/`.

Pliki WebP oraz `deck_assets.json` znajdują się w pakiecie `Steel_Magic_Integracja_Kart_v7.zip` (92 pliki WebP, 46 jednostek). Nie należy oznaczać wdrożenia jako zakończonego bez rzeczywistego umieszczenia plików na gałęzi testowej i testu HTTP 200 dla każdej ścieżki.

`card-assets-adapter.js` jest opcjonalny i zachowuje ikony zastępcze przy braku manifestu. Produkcja pozostaje bez zmian.
